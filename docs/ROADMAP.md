# Roadmap

Phase 1: project scaffold and local Docker runtime

Phase 2: auth/security baseline (custom user model, login/logout, role groups)

Phase 3: customer/vehicle/repair-order domain

Phase 4: billing/payments

Phase 5: shop-facing UI

Phase 6: production hardening (secure settings, HTTPS, admin hardening, backups)

Phase 7: hosted / internet-accessible web deployment with HTTPS and backups

This roadmap should guide slice planning but can change after implementation
review and user feedback.
