# Handoffs

Implementation handoffs and review reports should follow a consistent format so
future reviewers can quickly understand scope, validation, and remaining risk.

Expected handoff report format:

```text
Summary:
- ...

Files changed:
- ...

Validation performed:
- Command: ...
  Result: ...

Acceptance criteria status:
- [x] ...
- [ ] ...

Known issues / deviations:
- ...

Recommended next step:
- ...
```
